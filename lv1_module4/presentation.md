# 모듈 ④ 픽앤플레이스 자세 추정과 궤적 생성 발표 자료

## 파이프라인 전체 구조

카메라 점군을 입력으로 받고, 모듈 ③의 좌표변환으로 base 기준으로 옮긴다. PCA로 물체 주축을 찾고 Kabsch로 알려진 대응점 사이의 회전과 병진을 추정한다. 마지막으로 위치는 큐빅 스플라인, 자세는 quaternion SLERP로 보간해 목표 자세까지의 궤적을 만든다.

    점군 생성 → PCA 주축 → Kabsch 정합 → 이상치 제거
       → camera 좌표에서 base 좌표로 변환
       → 위치 스플라인 + 자세 SLERP
       → 60프레임 demo.gif

## 자세 추정 결과와 오차

길쭉한 점군은 공분산의 첫 번째 고유값이 가장 크므로 첫 주축이 물체의 긴 방향을 나타낸다. Kabsch는 중심을 제거한 두 점군의 교차 공분산을 SVD로 분해하고, 반사가 발생하면 행렬식이 1이 되도록 보정한다. 잡음이 포함된 대응점에서도 회전행렬과 병진을 추정하고, 정합 전후 RMSE와 회전각 오차로 결과를 평가했다.

## 노이즈·점 개수가 정확도에 미친 영향

노이즈 표준편차가 커질수록 Kabsch 회전 오차가 증가했다. 같은 노이즈에서는 점 개수가 30개에서 90개, 270개로 늘어날수록 평균 오차가 감소했다. 독립적인 측정이 많아지면 우연한 노이즈가 평균에서 상쇄되기 때문이다. 구형 점군은 고유값들이 비슷해 어떤 방향도 뚜렷한 주축이 되지 않으므로 PCA 축이 불안정했다.

## 구현의 한계

PCA는 물체의 형상이 구형이거나 대칭적이면 방향을 안정적으로 정하지 못한다. Kabsch는 대응점이 올바르게 짝지어졌다는 가정이 필요하다. 최소자승 평면 피팅은 이상치가 많거나 물체가 모델의 기본 평면과 크게 다르면 영향을 받는다. 실제 로봇에서는 센서 캘리브레이션 오차, 가림, 점군 밀도 차이, 시간 지연도 함께 고려해야 한다.

## 개선안

점군 전처리에 voxel downsampling과 통계적 이상치 제거를 추가하고, 대응점이 불명확한 경우에는 RANSAC과 ICP를 조합할 수 있다. PCA 축의 부호와 쿼터니언 부호는 시간 방향으로 연속성을 유지하도록 정규화한다. 실제 제어기에서는 jerk까지 제한하는 궤적 생성과 충돌 검사, 속도·가속도 한계 검사를 추가한다.

## 시연 결과

demo.gif는 현재 그리퍼 자세에서 PCA로 추정한 목표 자세까지 60개 프레임으로 이동한다. 위치는 중간에 위로 들어 올렸다가 목표 위치로 내려오는 큐빅 스플라인을 사용하고, 회전은 시작·목표 쿼터니언 사이의 SLERP를 사용한다. 각 프레임의 회전 변화량 표준편차와 위치 가속도 점프를 계산해 궤적 품질을 확인했다.
